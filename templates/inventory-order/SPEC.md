# 在庫・発注管理テンプレート仕様

架空の商品10件を使ったステージ0の動作確認用テンプレート。各シートの1行目が見出しで、2〜11行目が商品データ。

## 商品マスタ

| 列 | 項目 | 定義 |
| --- | --- | --- |
| A | 商品名 | 商品ごとに一意の名前。在庫台帳にも同じ名前を登録する。 |
| B | 単価 | 1個あたりの単価（円）。 |
| C | 発注点 | 現在庫と発注残の合計を比較する基準数量（個）。 |
| D | 安全在庫 | 欠品に備える数量（個）。参考項目。 |
| E | リードタイム日数 | 発注から入庫までの所要日数。参考項目。 |

## 在庫台帳

| 列 | 項目 | 定義 |
| --- | --- | --- |
| A | 商品名 | 商品マスタと一致する名前。1商品につき1行。 |
| B | 現在庫 | 手元にある数量（個）。 |
| C | 発注残 | 発注済みで未入庫の数量（個）。発注残がなければ 0。 |
| D | 入庫予定日 | 発注残の入庫予定日。予定がなければ空欄。参考項目。 |

## 発注リスト

| 列 | 項目 | 定義 |
| --- | --- | --- |
| A | 商品名 | 商品マスタから参照する商品名。 |
| B | 現在庫 | 商品名が一致する在庫台帳の現在庫（個）。 |
| C | 発注点 | 商品名が一致する商品マスタの発注点（個）。 |
| D | 発注要否 | 現在庫と発注残の合計が発注点未満なら「要」、発注点以上なら「不要」。 |
| E | 発注数量 | 発注点に達するために追加で必要な数量（個）。不足がなければ 0。 |

### セルに設定した式

以下は2行目の式。3〜11行目では相対参照の行番号が変わり、絶対参照の検索範囲は共通。

| セル | 式 | 処理 |
| --- | --- | --- |
| A2 | `='商品マスタ'!A2` | 商品名を取得する。 |
| B2 | `=VLOOKUP(A2,'在庫台帳'!$A$2:$C$11,2,FALSE)` | 商品名の完全一致で現在庫を取得する。 |
| C2 | `=VLOOKUP(A2,'商品マスタ'!$A$2:$C$11,3,FALSE)` | 商品名の完全一致で発注点を取得する。 |
| D2 | `=IF(B2+VLOOKUP(A2,'在庫台帳'!$A$2:$C$11,3,FALSE)<C2,"要","不要")` | 発注残を取得し、現在庫との合計を発注点と比較する。 |
| E2 | `=MAX(0,C2-B2-VLOOKUP(A2,'在庫台帳'!$A$2:$C$11,3,FALSE))` | 発注点から現在庫と発注残を引き、0以上にする。 |

## 動作確認

`inventory-order.xlsx` を開く。Google スプレッドシートではファイルをインポートして確認できる。

1. 初期状態の発注リストで10件すべてに「要」か「不要」が表示されることを確認する。
2. 在庫台帳の B2（試作商品01の現在庫）を 12 から 17 に変更する。
3. 発注リストの D2 が「要」から「不要」に、E2 が 5 から 0 に変わることを確認する。発注残は 3、発注点は 20 なので、変更後の合計は発注点と等しい。

## ブックの再生成

Python に `openpyxl` をインストールし、このディレクトリで `python generate.py` を実行すると、同じ場所に `inventory-order.xlsx` を生成する。
