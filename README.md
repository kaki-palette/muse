# muse

フィリップ（Muse）⇔ Codex の橋渡し用リポジトリ。副業関連のみに使う。

## 動き方

1. フィリップが情報をまとめ、Issue（指示書）を作る
2. Issue または PR への `@codex` コメントで Codex が着手する
3. Codex はブランチで作業し、PR（変更提案）で提出する
4. フィリップが PR を検証し、修正が要れば `@codex` で差し戻す
5. 最終判断（採用・公開・出品）は本人が行う

## 守ること

- 課金なし。APIキー方式は使わない（ChatGPTプランの枠内で動かす）
- 勤務先の資料・取引先名・実数値・内部手順は入れない。一般知識＋ダミーデータのみ
- 詳細な前提と却下済みの結論は `context/side-business-context-for-codex.md` を参照
