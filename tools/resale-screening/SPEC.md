# フリマ価格差せどり 候補判定・監視リスト仕様

Yahoo!フリマやメルカリの安値出品を仕入れ候補として判定し、監視対象の買いラインを管理する。各シートの1行目が見出しで、候補判定は2〜4行目、監視リストは2〜5行目に Issue #3 の実データを収録する。

## 候補判定

| 列 | 項目 | 定義 |
| --- | --- | --- |
| A | 商品名 | 仕入れ候補の商品名。 |
| B | 仕入れ先 | Yahoo!フリマ、メルカリなどのサービス名。 |
| C | 仕入れ先URL | 仕入れ候補の出品ページ。IssueにURLの記載がないサンプルは空欄。 |
| D | 仕入れ価格 | 商品の仕入れ価格（円）。 |
| E | 仕入れ送料 | 仕入れ時の送料（円）。送料負担がなければ 0。 |
| F | 想定売却価格（メルカリ売却済み中央値） | メルカリの売却済み価格の中央値（円）。 |
| G | 売却実績URL | 想定売却価格の根拠ページ。IssueにURLの記載がないサンプルは空欄。 |
| H | メモ | 任意の補足情報。 |
| I | 販売手数料 | 想定売却価格の10%（円）。 |
| J | 利益 | 売却価格から販売手数料、販売時のネコポス送料210円、仕入れ価格、仕入れ送料を引いた額（円）。 |
| K | 利益率 | 利益を想定売却価格で割った割合。 |
| L | 分岐売却価格 | 利益1,000円を確保するために必要な最小の売却価格（円）。 |
| M | 判定 | 利益1,000円以上は「○」、0円以上1,000円未満は「△」、0円未満は「×」。 |

### セルに設定した式

以下は2行目の式。行を追加する場合は計算列の式を新しい行にコピーする。計算に必要な数値が未入力の場合、または利益率の分母が0円の場合は、該当する計算結果を空欄で表示する。

| セル | 式 |
| --- | --- |
| I2 | `=IF(ISNUMBER(F2),F2*10%,"")` |
| J2 | `=IF(COUNT(D2:F2)=3,F2-I2-210-D2-E2,"")` |
| K2 | `=IF(AND(ISNUMBER(J2),F2<>0),J2/F2,"")` |
| L2 | `=IF(COUNT(D2:E2)=2,CEILING((D2+E2+210+1000)/0.9,1),"")` |
| M2 | `=IF(ISNUMBER(J2),IF(J2>=1000,"○",IF(J2>=0,"△","×")),"")` |

## 監視リスト

| 列 | 項目 | 定義 |
| --- | --- | --- |
| A | 対象商品 | 相場を追跡する商品名。 |
| B | メルカリ売却済み中央値 | 確認した売却済み価格の中央値（円）。未確定なら空欄。 |
| C | メルカリ売却済み最高値 | 確認した売却済み価格の最高値（円）。未確定なら空欄。 |
| D | 仕入れ送料の想定 | 仕入れ時に見込む送料（円）。送料負担がなければ 0。 |
| E | 買いライン | 利益1,000円を確保できる仕入れ価格の上限（円）。 |
| F | 最終確認日 | 売却実績を最後に確認した日。初期値は4件とも 2026-11-26。 |
| G | メモ | 確認状況や再確認の予定など。 |

### セルに設定した式

| セル | 式 |
| --- | --- |
| E2 | `=IF(AND(ISNUMBER(B2),ISNUMBER(D2)),FLOOR(B2*0.9-210-1000-D2,1),"")` |

中央値または仕入れ送料の想定が未入力なら買いラインを空欄で表示する。行を追加する場合は E 列の式を新しい行にコピーする。

## 動作確認

`resale-screening.xlsx` を開く。Google スプレッドシートではファイルをインポートして確認できる。

1. 候補判定の利益が上から 1,790円、1,300円、1,070円で、判定が3件とも「○」であることを確認する。
2. 監視リストの買いラインが上から 4,640円、7,610円、5,270円、空欄であることを確認する。
3. 候補判定の D2（仕入れ価格）を 7,790円、8,790円、8,791円に順に変更すると、利益が 1,000円、0円、−1円となり、判定が「○」「△」「×」に変わることを確認する。
